# Software alternatives for Commons

Researched on October 14, 2026. This is an editorial shortlist for the site's stated purpose, a community hub for people rebuilding familiar tools in the open. It does not imply that these projects have joined Commons or endorsed it. No project records or accounts were created.

## Recommendation

Commons can support two related uses: finding software to use now, and finding an active rebuild to help develop. Put a familiar product and a concrete workflow at the start of discovery, such as "replace Photoshop for painting" or "replace Airtable for a shared database." Then show the project's actual readiness, license, activity evidence, and ways to contribute.

The replacement mappings and fit assessments below are editorial judgments based on the cited capabilities. They are not claims of complete compatibility. "Active" means a recent release or repository activity was observed. It does not establish security, project sustainability, or successful migration. Versions are examples verified during this research, not promises that they will remain the latest.

Start with Penpot, Graphite, PhotoCraft, Krita, Kdenlive, darktable, Excalidraw, Nextcloud, Immich, Baserow, Plane, Element, and Forgejo. Include Joplin with a separate server-license note. AFFiNE belongs in a clearly labeled mixed-license collection.

## Directories worth studying

| Directory | What the source establishes | Useful lesson for Commons |

| [AlternativeTo](https://alternativeto.net/about/) | Community recommendations organized around software a person already knows and wants to replace. | [awesome-selfhosted](https://github.com/awesome-selfhosted/awesome-selfhosted) and [its data repository](https://github.com/awesome-selfhosted/awesome-selfhosted-data) | Free software network services/web applications that can run on one's own servers; a separate machine-readable data source. | [Open Source Alternative To](https://opensourcealternative.to/) | An index explicitly organized as open-source alternatives to proprietary software. | Useful comparison for familiar-product mappings. Commons can provide a contribution path and a reasoned fit assessment alongside each result. |

These directories are discovery references. Do not bulk-copy descriptions, ratings, logos, or datasets without verifying the applicable rights. Prefer independently written summaries tied to the upstream project. The Commons member and activity model should remain separate from third-party reference entries.

## Fields the research supports

Every indexed entry should contain a canonical website, source repository, exact license/edition, software it can replace, specific workflows it covers, gaps, platforms, deployment choices, last verified date, and an activity-evidence link. Keep "usable replacement," "active rebuild," and "mixed/source-available components" visible enough to filter. These are editorial categories, not upstream certifications.

For community participation, link the upstream contribution guide and issue tracker first. Commons members can create discussions and offer help without claiming that the upstream maintainers have joined. Verified maintainers can later claim a listing and supply contribution needs.

An initial collection could be "Leave Adobe," with PhotoCraft and Graphite under active rebuilds, Krita for painting, Kdenlive for video editing, and darktable for RAW photography. A second could be "Own your workspace," with Nextcloud, Immich, Joplin clients, Baserow Community Edition, Plane Community Edition, Element, and Forgejo. Each collection should explain the workflow rather than imply product-wide parity.

## Evidence limits

GitHub API metadata and official release pages were checked live. Repository push timestamps were used only when a recent release was not an adequate signal. A push can include documentation or automation, so it is weaker evidence than a dated release. No applications were installed, migrations tested, or maintainers contacted. License labels here are source summaries for cataloging; exact component files remain authoritative.

PhotoCraft search results included a stale or unrelated `photocraft-app/photocraft` URL. The live API returned 404 for it. The verified upstream used in this report is `storytold/photocraft`, whose current README is more cautious about readiness than older indexed snippets.
